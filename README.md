# tech-pro-edits

Tech Pro Edits — Professional AI editing tools and creative projects.

Marketing site for **Sara**, an AI-assisted video editing studio. Built with React + Vite.

## Development

```bash
npm install
npm run dev
```

The dev server runs on port 3000. In the Base44 sandbox the app is served by
`docker-compose.base44.yml` from the environment repository.
